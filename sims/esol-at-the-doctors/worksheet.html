Tasks

  1. Read the start screen and tap Start.
  2. Answer all 6 questions in full sentences. Use Speak, Type or Tiles.
  3. If Dr Shah corrects you, read the tip and try again.
  4. Write down every answer that was not right first time, with the correct sentence.
  5. Look at the calendar on the wall. Write one sentence with since and one with for.
  6. Do it again without Grammar help and try to beat your score.

Test yourself

Circle one answer for each question, then check your answers in the simulation.

1. Which sentence is correct?
  1. I have it since Monday.
  2. I've had it since Monday.
2. Which sentence is correct?
  1. I've had it for four days.
  2. I've had it since four days.
3. Which sentence is correct?
  1. I have lifted some boxes on Monday.
  2. I lifted some boxes on Monday.
4. Which sentence is correct?

  2. I have taken some ibuprofen last night.
5. Which sentence is correct?
  1. No, I never had back pain before.
  2. No, I've never had back pain before.
