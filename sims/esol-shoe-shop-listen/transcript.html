At the shoe shop: listen and write it down

Transcript of the narration · Entry 3
▶ Open the simulation

Everything the narrator says, in order. Use it if you can't use sound, or to revise afterwards.

Before you start

Jenny

Hello. So, you'd like to change these boots for a size 6. I'm sorry, we haven't got a size 6 in the shop today. I can order them for you. So, here is some information for you. You might want to write this down.

Your clue

"You might want to write this down." This means: write down what I say next. It is important.

Information: set A

Exchange reference

Jenny says: Your exchange reference is BT 6 1 8 0 4. Write: BT61804

Manager

Jenny says: The shoe department manager is Mr Okafor. Write: Mr Okafor

Phone number

Jenny says: If the new boots aren't here by Friday, ring us on 01632 960 731. Write: 01632 960731

Information: set C

Website

Phone number

Name and Reference

Jenny says: Please speak to Daniel Hughes, and give him this reference: EX 4 0 6 2 8. Write: Daniel Hughes, EX40628

Ways to ask Jenny

1. Can you spell that, please?

Can you...? A question starts with Can.

2. Can you repeat that, please?

Can you...? A question starts with Can.

3. Can you say that again slowly, please?

Say it slowly: slow, slowly.

4. Can I check I have the correct information, please?

Can I check...? A polite way to check.

5. How do you spell that?

How do you spell...? Use do.

Listening tips

1. "oh" in a number

Write 0 (zero).

2. "double five"

Write 55.

3. "at" and "dot" in an email

Write @ and a full stop: shoes@brookesstores.co.uk

4. "slash" in a website

Write /

At the end

Jenny

That's everything. Is there anything else I can help you with today? No? OK. Thank you for coming in. Goodbye.
