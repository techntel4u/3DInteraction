What you'll learn

Learning outcomes – by the end, you can…

  • Name each part of the sTR5 retention system (force frame, rail frame, external cap, carrier frame, PnP cover cap) and explain what it does.
  • Install a Threadripper CPU in the correct order, including the screw sequences (loosen 3→2→1, tighten 1→2→3) and using a torque-limiting T20 driver.
  • Explain why you isolate the power and use ESD precautions before handling the CPU and motherboard.
  • Apply thermal paste sensibly and fit a cooler, then connect it to the CPU_FAN header.
  • Spot the common mistakes and explain the damage each one can cause.

Common misconceptions

MisconceptionCorrect idea
"The pins are on the CPU, like older AMD chips."sTR5 is an LGA socket. The contacts are in the motherboard socket; the CPU has flat pads. Bent contacts damage the board.
"Take the plastic socket cover off first."Leave the PnP cover cap on until the carrier and CPU are in the rail frame, so the contacts are exposed for as little time as possible.
"Screw order doesn't matter as long as it's tight."Tighten 1→2→3 to the set torque (about 1.6 N·m; check the manual). The wrong order or over-tightening can seriously damage the socket or CPU.
"Take the CPU out of the orange frame to fit it."Never separate them. The carrier frame holds the CPU in the only correct orientation.
"More thermal paste means better cooling."Too much paste lowers heat conductivity. If the cooler has paste pre-applied, don't add more.
